# Code of conduct

We want a welcoming, practical space for people using and improving this add-on.

Be respectful and constructive. Assume good intent, explain technical disagreements with evidence, and make room for different experience levels. Harassment, discrimination, personal attacks, and disclosure of another person's private information are not acceptable.

These expectations apply in issues, pull requests, reviews, and other project spaces. Rob Taylor, as maintainer, may edit or remove harmful content and restrict participation when needed.

To report a conduct concern, contact the maintainer privately through the contact options on [Rob Taylor's GitHub profile](https://github.com/manix84). Do not post a sensitive report in a public issue. For a product security vulnerability, follow [SECURITY.md](SECURITY.md).
