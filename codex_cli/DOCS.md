# Codex CLI SSH

This add-on provides a dedicated SSH login named `codex`. The Codex executable is installed in the container image. The SSH host key and the `codex` user's home directory, including Codex login state, are stored in the add-on's persistent `/data` volume.

## Setup

1. Add `https://github.com/manix84/ha-codex-cli-addon` to the Home Assistant Add-on Store's repositories and install **Codex CLI SSH**.
2. In this add-on's configuration folder, usually `/addon_configs/<repository-id>_codex_cli/`, create a file called `authorized_keys` containing your SSH **public** key, one key per line. The file must not contain a private key. The repository ID is generated by Home Assistant; find the exact folder name in the add-on configuration file browser.
3. Start the add-on. Its default host port is `22223`; adjust the port in the add-on Network settings if needed.
4. From your computer, run `ssh -p 22223 codex@<home-assistant-address> 'codex --version'`.
5. Sign in from a terminal with `ssh -t -p 22223 codex@<home-assistant-address> 'codex login --device-auth'`, then check `codex login status` over SSH.
6. Configure the Codex desktop SSH connection for `codex@<home-assistant-address>` on the chosen port. Test that the desktop app opens a task in `/homeassistant` or `/addons`.

The add-on maps the Home Assistant configuration folder at `/homeassistant` and local add-on source at `/addons`, both writable. Only install this on a trusted Home Assistant system, and restrict network access to the SSH port. The add-on does not expose a web interface or request Supervisor API access.

## Updates and backup

The Codex version is pinned in `Dockerfile`. To update it, change the version and the add-on version, then rebuild. Back up the add-on's data before rebuilding or reinstalling. Keep the persistent `/data` volume if you want the SSH identity, login state, and workspace to survive an update.

If you need a shell inside the add-on, use the SSH connection on its own port. SSH into a different Home Assistant add-on will give you a different filesystem and will not find this Codex installation.
