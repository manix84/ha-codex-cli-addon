# Security policy

## Supported versions

Security fixes are targeted at the latest released add-on version on the default branch. Older versions may not receive fixes.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub's private vulnerability reporting for this repository, if available, through **Security → Advisories → Report a vulnerability**. If that option is unavailable, contact Rob Taylor privately through the contact options on [his GitHub profile](https://github.com/manix84) to arrange a private report. Do not include exploit details or credentials in a public message.

Useful reports include the affected add-on version, architecture, impact, reproduction steps, and a proposed fix if you have one. Remove tokens, SSH keys, Home Assistant secrets, and personal network details from logs and examples.

The maintainer will acknowledge reports and coordinate disclosure and remediation as capacity allows. No response or fix timeline is guaranteed.
