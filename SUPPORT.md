# Support

For installation or usage questions, check the [README](README.md) and [add-on documentation](codex_cli/DOCS.md), then search [existing issues](https://github.com/manix84/ha-codex-cli-addon/issues).

If you still need help, [open an issue](https://github.com/manix84/ha-codex-cli-addon/issues/new/choose) with the add-on version, Home Assistant architecture, what you expected, what happened, and relevant redacted logs. Never post `authorized_keys`, private keys, Codex authentication files, tokens, or Home Assistant secrets.

For vulnerabilities, follow the [security policy](SECURITY.md) instead of opening a public issue. For questions about Codex CLI itself, use [OpenAI's Codex documentation](https://learn.chatgpt.com/docs/codex/cli).
